# Judgment audit of the 72-item Today sample

Standards applied: docs/pedagogy/today/question-standards.md sections 1 to 7 and 12, and the standing rules in .claude/skills/question-bank-audit/LESSONS.md (steps 5 and 7 of the skill). Error behaviours were looked up by id from data/errors.json. No item was edited. This is one model reading, not the operator's verdict, and a distractor count below is my derivation of each option's value from its tagged BC-ERR record, done by hand; a count of 3 means I could reproduce all three values from the named error.

## Method and limits [single-source]

Each record was read once with its options, error paths, worked solution and figure alt text. For every distractor I recomputed the value the named error would produce and compared it with the stored option. I did not recheck keys, although every key I touched while deriving distractors agreed with my arithmetic. Difficulty is my own easy, medium or hard judgement, not the stored predicted probability. "Duplicate" means the same problem with new numbers inside this sample. Verdict rules: fix_distractor when a distractor does not follow from its tag, when one path fills all three distractors, when a distractor is a defensible second answer, or when the option set cues the key; fix_stem when the stem is wrong, asks for something the options cannot carry, or mislabels calculator use. No item earned reject and none earned fix_key_suspect.

## Patterns worth a mechanical check [inferred]

Four defects recur and could be linted rather than read. An mcq stem that asks the student to show work, a setup, units or a stated form, which the options cannot carry: 15 of 66 mcq items, all template items (ITM-GEN-01004-07, 04002-06, 04006-07, 06001-05, 06002-04, 99001-04, and nine calculator items with a show-the-setup clause). A calculator-rule stem asking for three decimals while an option is stored with fewer: 4 items. An area item with negative options: 3 items. Plain-text math with carets in P1 stems (ITM-AGT-01008-06, 01015-04, 02006-04, 02011-06, 03008-09), which renders raw if the client expects LaTeX. Indefinite-integral keys without + C (ITM-GEN-06018-05, 06019-09) are a habit gap the AP rubric would penalise, although the comparator already treats C as a constant.
