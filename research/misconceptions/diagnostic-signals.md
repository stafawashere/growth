# Diagnostic Signals, AP Calculus BC

A signal is one observable feature of a response together with the mastery state that feature is consistent with. Signals are not diagnoses. The `distinguish_by` column names the follow-up that separates the reading in the row from its rivals, and the section at the end collects the patterns where two very different failures produce nearly the same page.

## Signal patterns that separate failure types [inferred]

Each pattern below is a pair of responses that look similar and imply different mastery states. The mapping is from signal ids to the state the registry records for them; the reading is a conclusion drawn from the records, not a statement from an official document.

### Derivative correct but the units wrong

Signals: BC-SIG-04001, BC-SIG-02003, BC-SIG-04009, BC-SIG-05044, BC-SIG-06004. Mastery states implied: partially_mastered.

The calculus is finished and the naming of the quantity is not. The value earns its point and the units point is withheld separately, which is why this pattern is consistent with BC-ERR-99005 and not with a gap in the derivative skill itself. BC-SIG-02003 and BC-SIG-06004 are the sharper members of the group, because a rate reported in the units of the modelled quantity shows that the derived quantity was never named.

### Integral set up correctly but evaluated wrongly

Signals: BC-SIG-06001, BC-SIG-06022, BC-SIG-06021, BC-SIG-08004, BC-SIG-01003. Mastery states implied: partially_mastered, except BC-SIG-06021 which is not_mastered.

The setup point is earned and the answer point is not. BC-SIG-06001 and BC-SIG-01003 are consistent with arithmetic slips and with BC-ERR-99019 on premature rounding, so they support a presentation reading rather than a conceptual one. BC-SIG-06022 and BC-SIG-06021 are different: a missing chain rule factor or a substituted infinity symbol locates the failure inside the evaluation rule, and BC-SIG-06021 is consistent with BC-MIS-99008.

### Correct convergence test but the wrong conclusion

Signals: BC-SIG-10011, BC-SIG-10002, BC-SIG-10023, BC-SIG-10005, BC-SIG-10009, BC-SIG-10001. Mastery states implied: partially_mastered, except BC-SIG-10001 which is prerequisite_gap and BC-SIG-10006 which is not_mastered.

### One error is not a diagnosis

Every error record in `data/errors.json` carries a `non_conceptual_causes` list, and those lists are the reason a single observation must not be read as a misconception. The most frequent entries across the registry are: time pressure (299 error records); arithmetic slip (169 error records); misread of the question or the figure (109 error records); a copied template from a similar exercise (39 error records); misread of the prompt (37 error records); omission under time pressure (8 error records). A response showing one instance of BC-ERR-99019 or BC-ERR-99006 is consistent with any of these before it is consistent with a belief about rounding or about differentials.

The rule the rest of this file follows is that a misconception is worth raising only when the same signal repeats across parts or representations, and when the `distinguish_by` probe has been run and its result rules out the non-conceptual readings. Where that has not happened, the correct record to cite is the error, not the misconception.
