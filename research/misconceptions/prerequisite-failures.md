# Prerequisite Failures, AP Calculus BC

A prerequisite gap is one reading of an error, not the only one. Each row pairs an error record with the BC-PRQ prerequisites and earlier BC-SKL skills that the affected skills depend on, then names the alternative explanations the error record itself records, then gives the probe that separates the two. Rows appear only where the registry supplies at least one prerequisite for the skills the error touches.
