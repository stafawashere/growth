# Command Verbs in AP Calculus BC Free-Response Prompts

Derived from the prompt wording reproduced inside the cached scoring guidelines and from the cached free-response documents frq-23 through frq-26. Facts live in `../../data/taxonomies.json` under `command_verbs`. Prompt stems are paraphrased, never reproduced.

The catalogue separates the task verb from the instruction phrase attached to it, because the guidelines score them separately. A part that says to find a value and show the setup produces two points, one for the setup and one for the value (sg-25:2). A part that says to find a value with no attached instruction produces a single answer point earned with or without supporting work (sg-26:18).

## BC-CV-01 Find (a value, an expression, or a vector) [verified]

Scope shared. Sources sg-26:18, sg-25:18, sg-22:7.

Prompt form: Find.

Typical response the rubric rewards: A value or expression with whatever work the accompanying instruction demands; alone the verb does not compel shown work, and the rubrics then award the answer point with or without supporting work.

- sg-26:18 Q5(A) awards the answer point for an unsupported value while the antiderivative point needs work
- sg-25:18 Q4(c) asks to find two values and scores each as an unsupported answer with a label
- sg-22:7 Q2(b) asks to find speed and an acceleration vector and requires the setup to be evident

## BC-CV-02 Determine (whether, or which case holds) [verified]

Scope shared. Sources sg-24:4, sg-23:10, sg-21:24.

Prompt form: Determine.

Typical response the rubric rewards: A decision between named alternatives, carried by an analysis point plus a conclusion point.

- sg-24:2 Q1(d) asks to determine whether a rate is changing at an increasing rate and awards an answer with reason
- sg-23:10 Q3(c) asks to determine overestimate or underestimate and pairs a second derivative point with a reason point
- sg-21:24 Q6(c) asks to determine the radius of convergence and requires the radius to be stated explicitly

## BC-CV-03 Evaluate [verified]

Scope shared. Sources sg-26:18, sg-26:20, sg-23:17.

Prompt form: Evaluate.

Typical response the rubric rewards: A closed-form or numerical value obtained by carrying the computation through, normally scored as an antiderivative point plus an answer point.

- sg-26:18 Q5(A) evaluate a definite integral, scored antiderivative then answer
- sg-26:20 Q5(D) evaluate an improper integral, scored limit notation, antiderivative, answer
- sg-23:17 Q5(b) evaluate an improper integral or show it diverges

## BC-CV-04 Estimate [verified]

Scope shared. Sources sg-24:2, sg-21:2, sg-22:13.

Prompt form: Estimate.

Typical response the rubric rewards: A value derived from given data rather than from a closed form, with the difference and quotient or the sum visible.

- sg-24:2 Q1(a) estimate a derivative from a table, scored estimate with supporting work plus units
- sg-21:2 Q1(a) estimate a derivative from a table and interpret it with units
- sg-22:13 Q4(a) approximate a second derivative from a table, requiring at least a difference and a quotient

## BC-CV-05 Approximate [verified]

Scope shared. Sources sg-25:13, sg-26:3, sg-25:23.

Prompt form: Approximate.

Typical response the rubric rewards: A value from a stated approximation method, with the method's structure visible; the rubrics score the form of the method and the resulting value separately.

- sg-25:13 Q3(c) approximate an integral with a trapezoidal sum, scored form then value
- sg-26:3 Q1(B) approximate an integral with a midpoint sum, scored form then approximation with supporting work
- sg-25:23 Q5(D) approximate a function value by Euler's method, scored first step then answer

## BC-CV-06 Explain why [single-source]

Scope shared. Sources sg-26:10, sg-26:11.

Prompt form: Explain why.

Typical response the rubric rewards: A written argument naming the property that makes the claim hold, tied to the object the prompt names.

- sg-26:10 Q3(A) explain why a figure could not be a slope field, scored as a single explanation point
- sg-26:11 lists communication failures that do not earn the explanation point
- sg-26:11 allows a local argument at any point of the field in place of a global one
- Note: One question in the corpus read uses this stem, so tagged single-source.

## BC-CV-07 Justify your answer [verified]

Scope shared. Sources sg-25:5, sg-25:19, sg-23:15.

Prompt form: Justify your answer.

Typical response the rubric rewards: A global argument, not merely a local one; sign analysis across the whole interval, a candidates test at every candidate, or theorem hypotheses plus conclusion.

- sg-25:5 Q1(D) a local First or Second Derivative Test argument does not earn the justification point
- sg-25:19 Q4(d) a candidates test must evaluate at every candidate and no others
- sg-23:15 Q4(d) a response that does not consider both endpoints does not earn the justification point

## BC-CV-08 Give a reason for your answer [verified]

Scope shared. Sources sg-25:17, sg-26:15, sg-26:11.

Prompt form: Give a reason for your answer.

Typical response the rubric rewards: A shorter written reason than a justification, but one that must be tied to the object the prompt names rather than to a derived object.

- sg-25:17 Q4(b) the reason must tie to the given graph, and reasoning from the second derivative earns the answer point only
- sg-26:15 Q4(B) the same split, with ambiguous terms such as the function rejected
- sg-26:11 Q3(C) a concavity reason earns the reason point only when the sign point was earned

## BC-CV-09 Give reasons for your answers [single-source]

Scope shared. Sources sg-26:17, sg-23:7.

Prompt form: Give reasons for your answers.

Typical response the rubric rewards: Two separate conclusions each carrying its own reason, scored as separate points.

- sg-26:17 Q4(D) awards one point for the minimum with reason and one for the maximum with reason
- sg-26:17 special case where both locations are correct but the justification is insufficient earns one of the two
- sg-23:7 Q2(c) asks for two findings in one part and scores three points across them
- Note: The plural stem appears once in the corpus read, so tagged single-source.

## BC-CV-10 Interpret the meaning of a value or expression in context [verified]

Scope shared. Sources sg-26:3, sg-23:2, sg-23:4.

Prompt form: Interpret the meaning.

Typical response the rubric rewards: A sentence in the context of the problem naming the quantity, its value where one is asked for, and the interval or instant it applies to.

- sg-26:3 Q1(B) the interpretation must include the quantity that arrives and the interval
- sg-23:2 Q1(a) must reference the accumulated quantity and the interval
- sg-23:4 Q1(d) must give the changing rate and the instant, and sign language must match the presented value

## BC-CV-11 Using correct units [verified]

Scope shared. Sources sg-23:2, sg-21:2, sg-21:3.

Prompt form: Using correct units.

Typical response the rubric rewards: Units carried into the interpretation; the rubrics read them in the interpretation when they conflict with units on the value.

- sg-23:2 Q1(a) pairs the instruction with an interpretation with units point
- sg-21:3 states units need not be repeated but that conflicting units are read from the interpretation
- sg-21:2 Q1(a) scores interpretation with units as one point

## BC-CV-12 Indicate units of measure [verified]

Scope shared. Sources sg-25:11, sg-26:2, sg-22:13.

Prompt form: Indicate units of measure.

Typical response the rubric rewards: A separate units point, earned whether or not the units are attached to the numerical value.

- sg-25:11 Q3(a) units earned whether or not attached to a value
- sg-26:2 Q1(A) same wording, with a compact equivalent form accepted
- sg-22:13 Q4(a) units may be written in any equivalent form but need a presented value

## BC-CV-13 Show the setup for your calculations [verified]

Scope shared. Sources sg-25:2, sg-26:9, sg-25:7.

Prompt form: Show the setup for your calculations.

Typical response the rubric rewards: The expression that the calculator evaluated, written before the value; the rubrics score the setup and the value as separate points.

- sg-25:2 Q1(a) average value formula point precedes the answer point
- sg-26:9 Q2(D) same split for a polar average value
- sg-25:7 Q2(b) integrand points precede the answer point

## BC-CV-14 Show the work that leads to your answer [verified]

Scope shared. Sources sg-26:14, sg-26:15, sg-25:11, sg-23:10.

Prompt form: Show the work that leads to your answer.

Typical response the rubric rewards: Intermediate steps rather than a finished value; unsupported answers are named in the rubrics as failing the work point.

- sg-26:14 Q4(A) an unsupported answer earns the answer point but not the setup point
- sg-25:11 Q3(a) the quotient template alone is not sufficient, a value must be produced
- sg-23:10 Q3(b) an unsupported approximation does not earn the approximation point

## BC-CV-15 Write, but do not evaluate, an expression or integral [verified]

Scope shared. Sources sg-26:19, sg-22:2.

Prompt form: Write, but do not evaluate.

Typical response the rubric rewards: An unevaluated integral expression with correct limits and integrand; no numerical value is required or rewarded.

- sg-26:19 Q5(B) form of integrand point plus answer point for the unevaluated integral
- sg-26:19 Q5(C) form of arc length integral point plus answer point
- sg-22:2 Q1(a) the response must be a definite integral with correct limits

## BC-CV-16 Label your answers [verified]

Scope shared. Sources sg-25:18, sg-22:10, sg-23:6.

Prompt form: Label your answers.

Typical response the rubric rewards: Each value tagged with the quantity it represents; unlabelled values earn nothing.

- sg-25:18 Q4(c) unlabelled values earn neither point
- sg-22:10 Q3(a) a single value must be labelled to earn any point
- sg-23:6 Q2(a) components may be listed separately as long as they are labelled

## BC-CV-17 Sketch a solution curve [single-source]

- sg-23:9 Q3(a) the curve must pass through the point, reach near both edges, and lie below the equilibrium segments
- sg-24:9 Q3(a) same single solution curve point
- sg-23:9 states only the portion within the given field is considered

## BC-CV-18 Use a derivative test to determine [single-source]

Scope BC_only. Sources sg-26:8, sg-24:10.

Prompt form: Use a derivative test to determine.

Typical response the rubric rewards: A classification of a critical point supported by first or second derivative analysis; the test need not be named, and a candidates test is explicitly rejected.

- sg-26:8 Q2(C) the response must correctly classify the critical point with analysis using a derivative test
- sg-26:8 states a candidates test is not sufficient justification for this point
- sg-24:10 Q3(b) scores the sign consideration, the location, and the classification separately
- Note: The explicit stem appears once in the corpus read, so tagged single-source.

## BC-CV-19 Must there be a value, or is there a time, such that [verified]

Scope shared. Sources sg-25:12, sg-26:5, sg-23:3.

Prompt form: Must there be, or is there.

Typical response the rubric rewards: An existence claim built from a named theorem's hypotheses, the bracketing values, and an explicit yes.

- sg-25:12 Q3(b) requires bracketing values, a continuity statement, and a yes
- sg-26:5 Q1(D) states yes with the theorem named is not sufficient
- sg-23:3 Q1(b) requires the difference point and rejects an appeal to the Intermediate Value Theorem

## BC-CV-20 Show that a stated result holds [verified]

Scope shared. Sources sg-25:26, sg-25:22, sg-22:21.

Prompt form: Show that.

Typical response the rubric rewards: A derivation ending on the stated target, or an inequality connecting a computed bound to the stated number.

- sg-25:26 Q6(C) the verification point is earned by a chain landing on the given form
- sg-25:22 Q5(c) the analysis point requires an explicit connection to the stated bound
- sg-22:21 Q6(b) a response stating the error equals the bound does not earn the point

## BC-CV-21 Using the ratio test, find the interval of convergence [verified]

Scope BC_only. Sources sg-25:24, sg-22:20, sg-21:24.

Prompt form: Using the ratio test.

Typical response the rubric rewards: A ratio of consecutive terms, a limit, an interior interval, endpoint substitution, and endpoint analysis, scored as separate points.

- sg-25:24 Q6(a) scores ratio, limit, interior, both endpoints, and analysis as five points
- sg-22:20 Q6(a) scores the same sequence as four points
- sg-21:24 Q6(c) scores ratio, limit, and radius

## BC-CV-22 Use separation of variables to find a particular solution [verified]

Scope shared. Sources sg-26:12, sg-26:13, sg-23:12, sg-21:20.

Prompt form: Use separation of variables.

Typical response the rubric rewards: A separated equation, antiderivatives on both sides, a constant of integration resolved by the initial condition, and the solved function.

- sg-26:13 Q3(D) states a response with no separation earns none of the five points
- sg-23:12 Q3(d) states the same for its four points
- sg-21:20 Q5(c) states a response with no constant of integration earns at most three of five

## BC-CV-23 Use Euler's method with a stated number of steps [verified]

Scope BC_only. Sources sg-25:23, sg-24:17, sg-21:19.

Prompt form: Use Euler's method.

Typical response the rubric rewards: The stated number of steps with the correct initial condition, step size, and derivative expression, followed by the approximation.

- sg-25:23 Q5(D) requires the first step with correct initial condition, step size, and derivative expression
- sg-24:17 Q5(c) requires two steps with at most one error
- sg-21:19 Q5(b) allows a labelled table in place of explicit expressions

## BC-CV-24 Use a named sum with the indicated subintervals to approximate [verified]

Scope shared. Sources sg-25:13, sg-26:3, sg-22:15.

Prompt form: Use a Riemann or trapezoidal sum with the indicated subintervals.

Typical response the rubric rewards: A sum of the named type over the named subintervals, with every factor visible; the sum's form and the resulting value score separately.

- sg-25:13 Q3(c) requires three terms each a product of two factors, at least five of six correct
- sg-26:3 Q1(B) the same five of six rule for a midpoint sum
- sg-22:15 Q4(c) seven of eight factors for four subintervals

## BC-CV-25 Use the Lagrange error bound to show [single-source]

Scope BC_only. Sources sg-25:22, sg-23:20.

Prompt form: Use the Lagrange error bound.

Typical response the rubric rewards: The bound written with the maximum derivative, the factorial, and the distance power, then connected to the target by an inequality.

- sg-25:22 Q5(c) scores the form of the error bound and the analysis separately
- sg-23:20 Q6(b) scores the form and the explicit inequality separately
- sg-25:22 rejects a response declaring the error equal to the bound
- Note: Two documents in the corpus read carry this stem, so tagged single-source.

## BC-CV-26 Write the first nonzero terms and the general term [verified]

Scope BC_only. Sources sg-25:26, sg-22:22, sg-26:23.

Prompt form: Write the first nonzero terms and the general term.

Typical response the rubric rewards: A stated count of nonzero terms plus a closed form for the general term, listed or inside a series.

- sg-25:26 Q6(B) scores first three terms and the general term as separate points
- sg-22:22 Q6(c) scores first four terms and the general term as separate points
- sg-26:23 Q6(D) scores two terms then the remaining term for the combined series

## BC-CV-27 Write the Taylor or Maclaurin polynomial of a stated degree [verified]

Scope BC_only. Sources sg-25:22, sg-23:19, sg-23:21.

Prompt form: Write the nth-degree Taylor polynomial.

Typical response the rubric rewards: A polynomial in powers of the centre, to the stated degree and no higher, with no trailing ellipsis.

- sg-25:22 Q5(b) any terms of degree greater than two or a trailing ellipsis loses the remaining-term point
- sg-23:19 Q6(a) the same rule for a fourth-degree polynomial
- sg-23:21 Q6(c) the same rule for a second-degree polynomial

- sg-26:4 Q1(C) accepts the rounded integer, several truncations, and the exact expression
